# homebrew-landfall

Homebrew tap for the [`landfall` CLI](https://github.com/landfalls-ai/landfall-cli).

## Install

```
brew tap landfalls-ai/landfall
brew install landfall
```

or in one line:

```
brew install landfalls-ai/landfall/landfall
```

## Upgrading

```
brew upgrade landfall
```

## Releasing a new version

This tap's `Formula/landfall.rb` is updated manually whenever `landfall-cli` cuts a new
release — see [`landfall-cli`'s `RELEASING.md`](https://github.com/landfalls-ai/landfall-cli/blob/main/RELEASING.md)
for the full runbook.
